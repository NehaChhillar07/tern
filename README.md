# Tern

**Your AI study-abroad counsellor.** Tern is named after the Arctic tern, the bird with the longest migration on Earth. It helps students and working professionals move from profile analysis to shortlisting, applications, offers, visa and departure, for universities in the UK and Europe.

## Run it

```bash
pnpm install
```

```bash
pnpm dev
```

Open http://localhost:3000. The design tokens are at `/design`.
